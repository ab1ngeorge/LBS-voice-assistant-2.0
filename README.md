# LBS Voice Assistant

AI Voice Assistant for LBS College of Engineering, Kasaragod (LBSCEK).

## Technologies

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
- Supabase Edge Functions
- Groq API

## Getting Started

```sh
# Install dependencies
npm install

# Start development server
npm run dev
```

## Deployment

Build the project for production:

```sh
npm run build
```
